How payments flow

  • 1. Customer picks a methodAny method you have switched on shows up in the Add money popup.
  • 2. They payUPI gateway, manual UPI QR, or a crypto address, depending on the method.
  • 3. The wallet is creditedAutomatically for the gateway once it confirms, or by you approving a manual or crypto deposit.
  • 4. They buy cardsThe wallet balance is what pays for a card, and the card details are released at once.

Notes on your API keys

This is a static site, so any key saved here is visible in the page source. Use a sandbox key for testing, and for a live store add a small serverless function so the secret never reaches the browser.

Never use your live production secret key on a static site.
